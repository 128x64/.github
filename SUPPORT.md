# 128x64 Support

Welcome to 128x64 Support!

If you need help with a 128x64 project, encounter a problem, or have a general question, this document explains how to reach us.

## 1. Before Requesting Support

Before contacting us, please:

- Read the repository's README.
- Check the available documentation.
- Review existing GitHub Issues.
- Check GitHub Discussions, if enabled.
- Make sure you are using a supported version of the project.

Your question may already have an answer.

## 2. GitHub Issues

Use GitHub Issues for matters that require tracking or action, including:

- Bug reports.
- Reproducible problems.
- Feature requests.
- Documentation problems.
- Technical issues requiring investigation.

Please provide enough information for maintainers to understand the issue.

Do not submit security vulnerabilities through public Issues.

## 3. GitHub Discussions

When enabled, GitHub Discussions can be used for general community conversations, questions, suggestions, and project feedback.

Use Discussions for conversations that do not necessarily require a tracked development task.

If a discussion identifies a confirmed bug or actionable task, it may be moved into a GitHub Issue.

## 5. Response Expectations

128x64 aims to respond to support inquiries within seven days.

This is a maximum response target, not a guarantee of resolution within seven days.

Some requests may require additional investigation, clarification, or development work.

## 6. Security Issues

Do not report security vulnerabilities through public GitHub Issues or Discussions.

For security reports, follow the instructions in SECURITY.md.

Security reports should be submitted privately.

## 7. Support Limitations

128x64 does not guarantee support for every project, version, environment, or use case.

Support availability may depend on project status, available maintainers, technical complexity, and other circumstances.

We appreciate your patience and understanding.
